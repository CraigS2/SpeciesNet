Club Admin API Documentation

The club-admin API lets a club's own tools (a spreadsheet macro, a bot, a private dashboard, etc.) pull read-only data about the club and its members without a human logging in. Every request is authenticated with a single per-club API key rather than a user account.

Authentication

Generate a key from your club's Edit Club page, in the Club Admin API Key section — the same section this page is linked from. The raw key is shown exactly once at generation time; only a redacted hint is stored and displayed afterward. Regenerating a key immediately invalidates the previous one.

Send it on every request as a header:

X-Club-Api-Key: <your-club-api-key>
Errors
StatusMeaningBody
403 Header missing entirely {"detail": "Club API key required."}
401 Header present but the key doesn't match any club {"detail": "Invalid club API key."}
The member parameter

Several endpoints scope results to one club member via a ?member= query parameter, matched against that member's username first, then their email (case-insensitive) if no username matches. If member is omitted, or doesn't resolve to a current member of your club, the endpoint returns an empty results list — not an error — so a typo or an ex-member username fails quietly rather than breaking a script.

Endpoints
  • Members
  • Species Kept
  • Species Instances
  • CARES Species
  • CARES Species Instances
  • BAP Submissions
  • BAP Leaderboard
GET /api/club-admin/members/

Every current member of your club.

Query parameters: none.

Example request

curl https://yourdomain.example.com/api/club-admin/members/ \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {"username": "fishkeeper42", "full_name": "Jane Doe", "email": "jane@example.com"},
    {"username": "cichlidguy", "full_name": "Bob Smith", "email": "bob@example.com"}
  ]
}
GET /api/club-admin/species-kept/

Distinct species a member is currently keeping (one row per species, even if they keep several instances of it).

Query parameters: member (required — see above).

Example request

curl "https://yourdomain.example.com/api/club-admin/species-kept/?member=fishkeeper42" \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {"name": "Pterophyllum scalare", "url": "https://yourdomain.example.com/species/42/"},
    {"name": "Symphysodon discus", "url": "https://yourdomain.example.com/species/17/"}
  ]
}
GET /api/club-admin/species-instances/

Every individual SpeciesInstance entry (a member's specific tank/log entry for a species) belonging to that member within your club — including species they no longer currently keep, unlike Species Kept above.

Query parameters: member (required).

Example request

curl "https://yourdomain.example.com/api/club-admin/species-instances/?member=fishkeeper42" \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {"name": "fishkeeper42's 55g Angelfish", "url": "https://yourdomain.example.com/speciesInstance/103/"}
  ]
}
GET /api/club-admin/cares-species/

Like Species Kept, but limited to species flagged as CARES (conservation priority) species, with a cares_registered flag showing whether that member already has a CARES registration on file for it.

Query parameters: member (required).

Example request

curl "https://yourdomain.example.com/api/club-admin/cares-species/?member=fishkeeper42" \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {
      "name": "Ptychochromis insolitus",
      "url": "https://yourdomain.example.com/species/88/",
      "cares_registered": true
    }
  ]
}
GET /api/club-admin/cares-species-instances/

Like Species Instances, limited to CARES species, with a photo URL when the member has uploaded one for that entry.

Query parameters: member (required).

Example request

curl "https://yourdomain.example.com/api/club-admin/cares-species-instances/?member=fishkeeper42" \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {
      "name": "fishkeeper42's Ptychochromis insolitus",
      "url": "https://yourdomain.example.com/speciesInstance/210/",
      "image_url": "https://yourdomain.example.com/media/images/2026/08/tank.jpg"
    },
    {
      "name": "fishkeeper42's second CARES tank",
      "url": "https://yourdomain.example.com/speciesInstance/211/",
      "image_url": null
    }
  ]
}
GET /api/club-admin/bap-submissions/

Every BAP submission recorded against your club's currently open BAP year. Club-wide — there is no member filter.

Query parameters: none. Returns {"results": []} if your club doesn't have BAP enabled, or has no open BAP year.

Example request

curl https://yourdomain.example.com/api/club-admin/bap-submissions/ \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {
      "species_name": "Symphysodon discus",
      "username": "cichlidguy",
      "full_name": "Bob Smith",
      "email": "bob@example.com"
    }
  ]
}
GET /api/club-admin/bap-leaderboard/

The BAP leaderboard for your club's currently open BAP year, ordered by points (highest first). Club-wide — there is no member filter.

Query parameters: none. Same empty-results conditions as BAP Submissions above.

Example request

curl https://yourdomain.example.com/api/club-admin/bap-leaderboard/ \
  -H "X-Club-Api-Key: YOUR_KEY"

Example response

{
  "results": [
    {"points": 145, "username": "cichlidguy", "full_name": "Bob Smith", "email": "bob@example.com"},
    {"points": 90, "username": "fishkeeper42", "full_name": "Jane Doe", "email": "jane@example.com"}
  ]
}
